# User Prompt

> when app parses the game data XML, if it finds an 'X', then it is treated as an obstacle.  It should be shown as a dark brown tile.
> That obstacle tiles must not be able to be moved in any direction.
> 
> create md fil

# Implementation Summary

The requested features were implemented across the following files:

1. **`Block.java`**: Added a new boolean property `isObstacle` to the class, constructor, and `copy` method.
2. **`LevelManager.java`**: Updated the XML parser logic. When parsing XML, if the cell is `"X"`, it sets `isObstacle = true` and assigns it a dark brown color (`#4B3621`). It still treats `"@"` as the target block (Red).
3. **`GameEngine.java`**: Added a check inside `canMoveTo()`. If the block has `isObstacle` set to `true`, it immediately returns `false`, preventing the block from being moved in any direction.
4. **`GameView.java`**: Updated the drawing logic in `onDraw()`. When drawing blocks, if a block is marked as an obstacle, it skips drawing the wooden texture image and instead renders the block using the dark brown fallback color we specified.
